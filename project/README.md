# Бот (BillSplitter)

Телеграм-бот для совместного учета расходов. Фиксирует траты участников и рассчитывает финальные взаимозачеты.

## Возможности
* Регистрация участников: через ID пользователя или вручную.
* Деление трат: автоматическое распределение на всех или выбор конкретных участников.
* Статус: детальный отчет по вложенным средствам и категориям расходов.
* Расчет: алгоритм минимизации транзакций для погашения долгов.
* Пинг должников: уведомление участников с детальным описанием их задолженностей.
* Групповой режим: поддержка работы в общих чатах.

## Установка и запуск

### 1. Требования
Python 3.10 или выше.

### 2. Зависимости
Используйте pip для установки необходимых пакетов:
pip install pyTelegramBotAPI python-dotenv

### 3. Конфигурация
Создайте файл .env в корневой директории:
BOT_TOKEN=ваш_токен_полученный_от_BotFather

### 4. Запуск
python main.py

## Настройка для работы в группах
Для корректной обработки текстовых сообщений от всех участников необходимо отключить режим приватности:
1. Откройте диалог с @BotFather.
2. Отправьте команду /setprivacy.
3. Выберите нужного бота.
4. Установите статус Disabled.
5. Перезапустите бота в группе (удалить и добавить заново).

## Порядок работы
1. Регистрация: Участники используют кнопку Регистрация для внесения своих имен в базу чата.
2. Добавление данных: Кнопка Добавить трату. Формат ввода: сумма имя описание.
3. Распределение: Выбор между делением на всех присутствующих в базе или выборочным списком.
4. Отчетность: Кнопки Статус (текущие балансы) и Расчет (финальная схема переводов).

## Технические сведения
* Библиотека: pyTelegramBotAPI.
* Хранение данных: Локальные JSON-файлы в директории pay_data. Структура данных разделена по ID чатов.
